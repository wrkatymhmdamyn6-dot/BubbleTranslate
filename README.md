# Bubble Translate

اپلیکیشن اندروید برای تشخیص متن روی صفحه (OCR) و نمایش ترجمه در همان محدوده، همراه با حباب شناور قابل جابه‌جایی.

## قابلیت‌ها

- تشخیص متن صفحه با Google ML Kit Text Recognition
- ترجمه با ML Kit Translation و دانلود مدل‌ها برای استفاده آفلاین
- نمایش ترجمه روی متن اصلی در قالب لایه شناور
- حالت استاندارد برای کل صفحه و حالت زیرنویس برای بخش پایینی صفحه
- انتخاب زبان مبدأ و مقصد
- حباب شناور برای روشن/خاموش‌کردن ترجمه زنده

## پیش‌نیازها

- Android Studio و Android SDK 34
- JDK 17
- دستگاه Android 9 (API 28) یا بالاتر

## ساخت و اجرا

1. مخزن را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. برنامه را روی دستگاه اجرا کنید.
4. از داخل برنامه زبان مبدأ و مقصد را انتخاب کنید.
5. گزینه «دانلود مدل‌ها» را با اینترنت اجرا کنید؛ مدل ترجمه پس از دانلود برای ترجمه آفلاین قابل استفاده است.
6. مجوز نمایش روی برنامه‌های دیگر را فعال کنید.
7. «شروع ترجمه زنده» را بزنید و مجوز ضبط صفحه Android را تأیید کنید.
8. با لمس حباب ترجمه را روشن یا خاموش کنید؛ نگه‌داشتن طولانی حباب سرویس را متوقف می‌کند.

## نکات مهم

- ضبط صفحه فقط پس از تأیید صریح کاربر از پنجره سیستمی MediaProjection آغاز می‌شود.
- مدل OCR زبان‌های مبدأ در کد تعریف‌شده پشتیبانی می‌کند؛ فارسی در فهرست زبان‌های مبدأ OCR این نسخه نیست، اما فارسی به‌عنوان زبان مقصد موجود است.
- اولین دانلود مدل‌ها به اینترنت نیاز دارد.
- فایل اصلی کد در مسیر `app/src/main/java/com/example/bubbletranslate/MainActivity.kt` قرار دارد.
